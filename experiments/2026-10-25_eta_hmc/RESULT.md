## 诊断：δU 为什么在一次 40 fs 提议内变化 5–9 kT（`diag_fast_dU.py`，`logs/diag_fast_dU.log`，181 2080 Ti）

rep1–4 的 S0 末帧各 5 条新速度的 MM 轨迹（20 步 × 2 fs，与 HMC 提议相同，不接拒），每步算 float64 的 C^ML、C^MM；
对 (x0, x20) 用反事实混合构型拆分 δU 的变化。约束：碰到配体的约束 17 条 = 配体 17 个 H，X–H 键长是约束的。

| 40 fs 内 δU 变化的来源（20 条轨迹的 sd） | kJ/mol | kT |
|---|---:|---:|
| δU 总变化 | 18.06 | 7.24 |
| 其中 C^ML 变化 / C^MM Coulomb / C^MM LJ | 20.74 / 15.35 / 10.70 | 8.31 / 6.15 / 4.29 |
| 只动配体（环境停在 x0） | 16.76 | 6.72 |
| 只做配体刚体运动 | 5.28 | 2.12 |
| 只动环境（配体停在 x0） | 10.23 | 4.10 |
| Ω 换水（同一 x20，用 x0 的水集合对比） | 6.30 | 2.52 |

δU(t)−δU(0) 的 sd：2 fs 4.54、4 fs 5.83、8 fs 11.22、12 fs 15.18、20 fs 20.71、40 fs 18.06 kJ/mol。
**更正（2026-10-25，用户核对并经复算确认）**：δU(0) 与 δU(20 fs)、δU(40 fs) 的相关系数仍为 0.582、0.610，不能说整个 δU 已去相关；准确结论是 10–20 fs 内出现了很大的快变分量。只有 4 个初始构型，不是稳态自相关测量。
C^ML_i 40 fs 变化最大的配体原子是 0、2、1（重原子，ML sd 12.9 / 9.4 / 8.3；同原子 C^MM_i sd 23.7 / 21.5 / 23.0，
但 C^MM 的逐原子变化在组内大部分相互抵消）。

“只动配体 H”的混合构型破坏了 X–H 约束长度（H 动、母原子不动），ML 变化 sd 50 kJ/mol、最大 +218，属人为几何，不作结论。

结论（只限所测）：
- 配体内部变形是 δU 快变的重要来源（只动配体 16.8 vs 只刚体 5.3），环境运动 10.2，Ω 换水 6.3。各反事实分量不能按方差相加：“总变化−只动配体−只动环境”的残差 sd 为 6.5 kJ/mol（复算确认）。
- C^ML 与 C^MM 对同一次内部变形响应不同；快变分量在 10–20 fs 内出现。
- 对 η-HMC 的含义：提议长到能移动构型（≳10 fs）时，δU 已带上很大的快变分量，η 大时接受率低；
  提议缩到 1–2 步（δU 变化 sd 4.5–5.8 kJ/mol）则每次模型调用只前进 2–4 fs。
- 哪一侧（ML 或 MM）的快速响应更符合物理，本诊断不能区分；具体是哪个内坐标（如 C=O 伸缩、酰胺弯曲）也未检验。
