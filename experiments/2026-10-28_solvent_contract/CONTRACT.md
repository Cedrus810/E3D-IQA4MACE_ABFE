## 2. 端点原子修正：用现有 η 路径，不新增模型基团 λ

对一个冻结端点 j，定义已可计算的逐原子局部差值：

    δu_(j,i)(x) = cML_(j,i)(x) − cMM_(j,i)(x)
    δU_j(x) = Σ_i δu_(j,i)(x)
    U_(j,η)(x) = V_j(x) + η δU_j(x),  η: 0 → 1.

在相同温度、坐标约束测度及能量基准下，配分函数存在且可以对 η 求导时：

    ∂F_(j,η)/∂η = <δU_j>_(j,η)
    A_(j,i) := ∫_0^1 <δu_(j,i)>_(j,η) dη
    Σ_i A_(j,i) = ∫_0^1 <δU_j>_(j,η) dη = a_j.

这里的 A 是本轮明确选择的“端点 η 路径原子归因”，不是原子分别做 EXP。
非线性的 log⟨exp⟩ 一般不能拆成独立原子 log⟨exp⟩ 之和。
环境与配体构象响应通过 U_(j,η) 的系综进入；只对原 MM 帧作普通均值不能替代它。

该定义只要求查询现有端点的原子能量，不要求模型提供力、坐标梯度、部分 dummy 的 Cbb 标签，
也不要求模型评价组内 λ。Ω 对坐标的硬切换不单独妨碍这个 η 导数恒等式，
但目标稳定性、能量确定性和实际混合仍须验证。

有限采样必须保留 MC 拒绝后重复的状态；不能仅对接受帧平均。
每个端点 A_(j,:) 只估计保存一次，前后相邻段和重采样始终复用同一条记录。

如果 a_j 使用相邻 η BAR，而 A_i 使用 η TI，有限样本 / 布点下两者不会保证完全一致：

    r_(η,j) = a_j^BAR − Σ_i A_(j,i)^TI.

必须报告 r、布点 / 时间块 / 多起点变化，不把 r 按原子数、能量或其他比例补进 A_i。

## 3. MM 原子项：明确自然参数延拓，再沿原 MM 桥接积分

定义 b_(k,i) 时只使用 MM，不改变现有物理窗口。
对当前拆除组 G_k，临时把组控制参数延拓为该组每个原子的独立控制参数；
在实际路径上仍令它们同步，其他组与当前主设计完全相同。

选定的延拓约定：

1. 电荷段：组内原子电荷 q_i=λ_(e,i) q_i^0；该组 LJ 保持开启。
   配体内部例外项、其余参数及 PME 实现沿用 bridge_mm System。
   对同步值 λ_(e,i)=s 的能量必须与现有 el_g=s 逐帧一致。
2. LJ 段：当前组电荷已关；每个 i–环境对沿用现有 Beutler 形式，
   只将组开关替换为所属配体原子的 λ_(v,i)。
   LJ 截断、例外及 LRC 必须保留并按同一延拓求导。
   对同步值 λ_(v,i)=s 的能量必须与现有 on_g=s 逐帧一致。

用这份完整 MM Hamiltonian 定义每原子导数，包含属于它的 PME、例外校正和 LRC；
不能用局部裸 Coulomb / LJ 对和代替完整 MM 导数。
这些项属于 MM 评价器，不要求 head 学会 PME。

对于 i∈G_k：

    b_(k,i) = ∫_1^0 <∂V_k^elec / ∂λ_(e,i)>_(λ_e=s, λ_v=1) ds
             + ∫_1^0 <∂V_k^vdw / ∂λ_(v,i)>_(λ_e=0, λ_v=s) ds.

对于 i∉G_k，定义 b_(k,i)=0；路径上这些原子的控制参数不变。
由链式法则及 TI：

    Σ_i b_(k,i) = ΔF_k^V.

这是总体与精确积分层面的恒等式。现有 MM bridge 仅实现了组参数与 BAR；
上述逐原子延拓、导数求值和同步参数等价检查尚未实现。
当前导出的完整 MM 帧可用于新增导数评价；不必因缺导数字段就先重跑 MD。

有限数据时，MM 原子 TI 与相邻 BAR 的差

    r_(MM,k) = ΔF_k^(V,BAR) − Σ_i b_(k,i)^TI

单独报告，不分摊。导数评价器需验证 Σ_i ∂V/∂λ_i 等于组参数的导数；
实际精度、窗口积分误差与采样误差要分别检查。

## 4. 逐步 × 逐原子的归因矩阵

当前逐组路线对应复合路径：

    E_(k−1) → V_(k−1) → V_k → E_k.

两端用各自端点的 η 路径（左端反向），中间用已经选定的纯 MM 去电荷 / 去 LJ 路径。
由这条路径定义：

    h_(k,i) := b_(k,i) + A_(k,i) − A_(k−1,i)
    Σ_i h_(k,i) = ΔF_k^V + a_k − a_(k−1) = ΔF_k^E.

整链每原子量为：

    f_i := Σ_k h_(k,i)
         = Σ_k b_(k,i) + A_(K,i) − A_(0,i)
         = Σ_k b_(k,i) − A_(0,i)       （全 dummy 的 A_(K,i)=0）
    Σ_i f_i = F_K^E − F_0^E.

**重要：h_(k,i) 不限于当步拆除组的原子。**
另一组的原子 i 若仍耦合，其耦合修正在 S_(k−1) 与 S_k 的系综中可能改变，
于是 A_(k,i)−A_(k−1,i)≠0。这是保留的跨组响应，不可静默置零。

因此区分两种组报告：

    台阶贡献 H_k := Σ_i h_(k,i)                 （原主设计的逐组解耦量）
    按原子所属组汇总 P_g := Σ_(i∈G_g) f_i       （原子归因按化学分组汇总）
    Σ_k H_k = Σ_g P_g = 总自由能，但 H_g 一般不等于 P_g。

统一报告 H[k,i] 矩阵及两种边际，不能把 P_g 冒充 H_g。
若产品要求“第 k 台阶只分给 G_k 的原子，且该组原子和恰等于 H_k”，
还需额外的响应分摊约定；当前数据与恒等式不唯一决定这种分摊，本轮不引入任意比例。

这套公式给出明确、可加和的路径归因，不承诺原子量与拆除顺序、参考 MM 或能量分解规范无关。
能量监督本身也不自动消除自由能归因的路径选择。
若只需总量，A_K−A_0 足够；若需台阶 / 矩阵，则需要所有共享 A_j。

## 5. 与 README 对角路径 / Shapley 表述的关系

对任一明确的光滑多参数自由能面 F(λ)，对角路径积分
∫ ∂F/∂λ_i dλ_i 有自己的加和规则；
离散 Shapley 则是所有移除排列的边际自由能平均。一般情况下二者不等。
固定一条对角路径不需要指定一个离散移除顺序，不意味着它等于排列平均。

本文按主设计保留当前逐组顺序，不切换为对角模型采样，也不宣称得到离散 Shapley 值。
独立枚举反例见 `formula_validation.json`：同一个有限状态自由能面上，
对角 TI 与全部 3! 排列平均的最大原子差为 0.152431 kJ/mol，总量仍一致。

概念参考：Sundararajan & Najmi, ICML 2020，
[The Many Shapley Values for Model Explanation](https://proceedings.mlr.press/v119/sundararajan20b.html)，
§2.1–2.2 区分离散排列平均与直线路径的连续归因。
本文的热力学公式由上面的配分函数 / 链式法则推导，并有自己的枚举验证；
该引用不作为分子采样验收证据。

## 6. 有限样本闭合与必须保留的误差

若台阶总量继续采用 MM BAR + η BAR，而原子采用上面的 TI：

    r_k = ΔF_k^(E,BAR-cycle) − Σ_i h_(k,i)^TI
        = r_(MM,k) + r_(η,k) − r_(η,k−1).

共享端点残差也应一致复用；整链中间 η 残差按同一记录抵消。
不能为了输出“严格加和”的小数，把尚未收敛的 r_k 分配到原子。
精确系综下的加和、同一数值积分中的算术加和、与独立 BAR 的一致性，是三种不同检查。

重采样要逐链 / 时间块重算 η 均值、MM 导数均值、各积分和 BAR，再组装整条矩阵。
本轮没有提供真实分子的校准置信区间。
