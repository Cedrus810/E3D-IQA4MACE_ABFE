# E3D-IQA4MACE · ABFE

[English](README.md) | [中文](README_zh.md) | **日本語**

**物理的にゲージ固定した等変ポテンシャルによる原子分解結合自由エネルギー —— 1 回の計算で、すべての原子に説明を。**

多くの等変 MLIP は `E = Σᵢ Eᵢ` と書きますが、メッセージパッシングがすべての
情報を各ノードに混ぜ込むため、ある原子の `Eᵢ` を分子内・静電・分極の各部分へ
一意に分解することはできません。配体原子の `Eᵢ` を λ 倍しても、その原子と環境
との相互作用を取り除いたことにはなりません。取り除かれるのは、相互作用と配体
自身の内部エネルギーの、原子ごとに異なる任意の混合です。

本プロジェクトはこの「取り除き」を厳密にします:

```
E = Σᵢ E_intra(i) + Σ_{i<j} D_ij          （分解。観測量に固定）
D_LE = Σ_{i∈L} Σ_{a∈E} D_ia                （配体–環境結合）
```

分解を**物理観測量にゲージ固定**すると（総エネルギーの単なる再パラメータ化では
なく）、結合を原子ごとの λᵢ でスケールして対角パスに沿って積分するだけで、
デカップリング自由エネルギーの原子分解が得られます。その総和は厳密に total と
一致し、原子の除去順序に依存しません —— すなわち Shapley 値です。費用は通常の
ABFE 1 回分だけ。

| | 原子分解 dG | QM 精度 | 分極 / 電荷移動 |
|---|---|---|---|
| MM-GBSA 残基別 | あり（信頼性なし） | なし | なし |
| MM ABFE グループ別デカップリング | あり | なし | なし |
| 素朴な `Σᵢ Eᵢ` MLIP | なし | あり | あり |
| **本研究** | **あり** | **あり** | **あり** |

## 状況 —— 進行中

ゲージ固定のプログラム（WP1–WP7）は完了し実測済み、最初の完全な五項モデルも
学習済みです。WP8の仕組みは構築・検証済み。欠けているのは実サンプリングによる
自由エネルギー計算です —— これまでの結果はすべて、帰属の計算をサンプリングの
収束から切り離すため、意図的に固定コンフォメーションの平均を取っています。
検証の階段：**A** 二量体 → **B** FreeSolv 溶媒和 → **C** SAMPL ホスト–ゲスト
→ **D** タンパク質–リガンド ABFE（現在は DES370K 二量体のステージ A 規模）。

- **陰性対照が再現される**（WP1）：IQA 教師なしでは、ノード/エッジ分割は
  自力では IQA に収束しません —— 合成ラベルで 28 倍、凍結 `mace-omol-0`
  バックボーンで 49 倍のズレ。教師を入れると、E/F 精度をほぼ変えずに再編成されます。
- **`L_int` が対の総和を固定**（WP3）：`Σ D_AB` は CCSD(T)/CBS 相互作用
  エネルギーと、228 のホールドアウト DES370K 系で **0.27 kcal/mol** に一致。
- **端点が厳密**（WP6）：λ がマスクすべきはエッジ能量ではなく*グラフ* ——
  エッジだけのスケーリングでは `U(R,0) ≠ U_L + U_E` が結合の 5.9% ずれます。
  グラフマスクは 6 つの一貫性テストすべてに合格。
- **順序非依存の帰属**（WP7）：対角パスは穷挙モンテカルロ Shapley と total の
  **0.82%** で一致。
- **SAPT 成分教師**（es/ex/ind/disp のチャネル別）：エッジごとのオラクルとの
  差を 85% 圧縮、実 SAPT データで 84–94%。境界の*総量*だけを教えると、各
  チャネルは真の成分の 3–7 倍になります —— ペアの非同定可能性の直接的な提示。
  作業点：`sapt+total`。
- **錬金ハミルトニアンが OpenMM で動く**（WP8）：`openmm.PythonForce` 経由なので
  TorchScript 化は不要で、λ は普通の属性です。端点の恒等式はブリッジを経ても
  1.2e-7 eV を保つ。

**最初の完全モデル**（arm D、五項 `E + F + L_int + L_IQA + L_SAPT`、凍結
`mace-omol-0`、ヘッドのみ学習）：バックボーン自身のエネルギーに対して
4.3 meV/atom、力 0.062 eV/Å、相互作用エネルギー 0.53 kcal/mol、SAPT 各成分
0.6–1.7 kcal/mol —— 教師なしベースラインより各チャネル 6–11 倍良く、その費用は
arm C に対する約 2 倍のエネルギー誤差。これは上限です：D は 32k ステップでも
まだ下降中。チェックポイントは `ckpt/`、数値は `logs/joint_*.json`。

**凝縮相**（Atenolol + 最大 100 水、バックボーンは `MACE-POLAR-1-M` に変更）：
二量体で学習したヘッドは -2.0 meV/交叉エッジ のエッジごとのバイアスを抱え、
系が大きくなると増幅します。凍結バックボーン自身がラベル付けしたクラスタで
7 倍に削減（サンプル外）、20 の MD フレームから引くとホールドアウトの対和は
0.35 eV 以内に入ります。ヘッドの総結合はクラスタが覆う交叉エッジ数を超えると
破綻します。 larger クラスタはその裾を直しますが、誤差を別の場所へ動かします
（`RESEARCH_PLAN_v2.md` §13.15–13.23）。

**アンカー型総エネルギー**（v3、2026-10-10 決定）：total は凍結バックボーンから
取り、`U = E_bb − Σᵢ(1−λᵢ)cᵢ` とし、ヘッドは分割だけを担います。ヘッドが
取りこぼした分は 1 つの cut 項として報告され、`Σᵢ dGᵢ + dG_cut = dG` が厳密に
成立します。恒等式はコード中で float64 まで確認済み（v3 §13.29）。cut 項の
ばらつきは n = 20–50 で 6–10 kT なので、cut は数窓を要します（§13.25, §13.37）。
ヘッドは錬金状態にわたってプーリングした非最小化 MD フレームで再学習しました。
ヘッドはクラスタが来るアンサンブルに適合するためです（§13.33–13.37）。

**未了**：アンカー型サンプリングに必要な MM 壁と ML/MM 系、実サンプリングによる
自由エネルギー計算（WP8/WP9）、そして実 IQA ラベル —— これまでのノードゲージの
結果はすべて合成教師を使っているため、示しているのは「凍結した特徴に*ある*ゲージを
課せる」ということであり、「*IQA* ゲージがそこにある」ではありません。

## 再現

環境：`e3nn`、`torch`、`mace-torch`、`pymbar`、`openmm`。
（開発環境：miniforge `openmm_dev`、e3nn 0.4.4 —— MACE-POLAR-1 のためにダウングレード
—— / torch 2.12.0 / mace-torch 0.3.16。完全なリストは STATUS.md）

```bash
# 1. DESRES から DES370K をダウンロードし
#    (https://www.deshawresearch.com/downloads/)、DES370K.csv をリポジトリ直下に置く。
# 2. 元素/電荷でフィルタした分割（hcno、organic、full）を作る：
python prepare_data.py

# 3. 実験列を実行する（陰性対照、ゲージ、端点、帰属、joint arms A–D）：
./run_queue.sh            # または各 test_*.py を個別に
```

各 `test_*.py` は `logs/` に JSON 記録を、`ckpt/` にヘッドのチェックポイントを
書きます（いずれも gitignore 済み）。上記の数値は `RESEARCH_PLAN_v2.md §13` 出典で、
そこに出典が引かれています。
